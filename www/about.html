About This Server

This is a custom-built HTTP server written entirely in C++ 98. It is designed to be robust, efficient, and compliant with the HTTP/1.1 standard.

Unlike traditional blocking servers, this project utilizes I/O Multiplexing (poll/epoll/kqueue) to handle multiple client connections simultaneously in a single thread. This ensures high performance even under load.
